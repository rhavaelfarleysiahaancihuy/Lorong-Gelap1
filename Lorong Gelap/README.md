# 1. Judul

**Lorong Gelap – 3D Horror Escape Game**

# 2. Nama

**Rhavael Farley Siahaan**

# 3. Deskripsi Project

**Lorong Gelap** adalah game horor 3D sederhana yang mengajak pemain menjelajahi sebuah gedung tua yang gelap dan penuh suasana menyeramkan. Pemain harus mencari **3 kunci** yang tersebar di beberapa ruangan untuk membuka pintu keluar.

Selama mencari kunci, pemain harus berhati-hati karena terdapat **monster** yang dapat mengejar pemain. Pemain juga memiliki **senter dengan baterai terbatas**, sehingga harus mencari baterai tambahan agar tetap dapat melihat dalam kegelapan.

Game dilengkapi dengan suasana gelap, lampu yang berkedip, suara langkah kaki, suara misterius, kabut, serta beberapa jumpscare untuk membuat permainan terasa lebih menegangkan.

# 4. Tujuan Project

Tujuan dari project ini adalah membuat sebuah game horor 3D yang **sederhana, menarik, dan dapat dimainkan**. Game ini dibuat untuk menerapkan konsep dasar pengembangan game seperti **pergerakan karakter, kamera, pencahayaan, sistem inventory, interaksi dengan objek, AI monster, UI, dan kondisi menang atau kalah**.

Selain itu, project ini bertujuan untuk melatih kemampuan dalam membuat game menggunakan teknologi yang tersedia di **Antigravity IDE**, sekaligus membuat pengalaman bermain yang menegangkan bagi pemain.
